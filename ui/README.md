## Current Status
WIP: This project is currently in development. The current version is a simple webapp with some static content and SSO Login. The next step is to allow users to link their discourse account.

## DMS Member Profile UI

Web UI for DMS members to update their profiles. Current Features:

- List / Connect discourse (talk.dallasmakerspace.org) account.

### Technical details

- Simple webapp based on Kotlin + Ktor + Thymeleaf + Bootstrap. Inspired
  by [this article](https://www.baeldung.com/kotlin/ktor-thymeleaf-web-application).
- Uses docker for deployment.
